Трекер для чтения веб-новелл и книг

Описание
Библиотека веб-новелл для сохранения прогресса чтения. Пользователь может управлять своей коллекцией и фильтровать ее по жанрам.

Структура страницы
1. Шапка с навигацией
2. Приветственный блок
3. Форма поиска по названию и жанру
4. Сетка из 6 карточек с новеллами (включая название, описание, жанр и статус)
5. Блок с дополнительной информацией
6. Подвал с информацией об авторе

Как открыть
Откройте файл index.html в браузере.
