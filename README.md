# Трекер для чтения веб-новелл и книг

## Описание
Библиотека веб-новелл для сохранения прогресса чтения. Теперь это полноценное интерактивное SPA-приложение (Vanilla JS), где пользователь может управлять своей коллекцией, добавлять новые книги, удалять их, а также фильтровать и сортировать список. Все данные сохраняются в браузере.

## Что было добавлено в Лабораторной работе №2
* **Динамический рендеринг:** Карточки теперь генерируются через JavaScript (State-Driven UI).
* **Поиск, фильтрация и сброс:** Мгновенный поиск по названию, фильтрация по жанрам (с кнопкой сброса) и сортировка (по алфавиту и рейтингу).
* **Добавление новелл:** Модальное окно с формой и клиентской валидацией (Constraint Validation API), включая выбор нескольких жанров через чекбоксы.
* **Удаление:** Реализовано через делегирование событий (Event Delegation).
* **Сохранение данных:** Использование `localStorage` для сохранения состояния между перезагрузками страницы.
* **Безопасность и отказоустойчивость:** Защита от XSS (вывод через `textContent`), защита верстки от длинных строк (`overflow-wrap`) и замена неработающих ссылок на обложки на заглушки (`img.onerror`).
